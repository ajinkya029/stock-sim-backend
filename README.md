A paper-trading backend built on the MERN stack. Users register, receive simulated
market prices in real time over WebSockets, place buy and sell orders, and track
their portfolio's cash, holdings, and profit and loss.

> Prices are generated by a random-walk simulator. They are **not** live market data.

## Features

- **Authentication:** register and log in with JWT. Passwords are hashed with bcrypt.
- **Live market feed:** 10 sample stocks tick every 2 seconds and are pushed to all connected clients.
- **Market orders:** buy and sell at the current simulated price, with cash and share checks.
- **Average cost tracking:** holdings keep a weighted average cost basis across multiple buys.
- **Portfolio analytics:** cash, holdings value, total equity, unrealized P&L (absolute and percent), and total return.
- **Trade history:** paginated record of every executed trade.
- **Private notifications:** each user receives `trade:executed` events only for their own trades.
- **Security basics:** Helmet headers, CORS allow-list, JSON body size limit, and rate limiting.
- **Graceful shutdown:** flushes in-memory prices to MongoDB before exiting.

## Getting Started

### Prerequisites

- Node.js 18 or later
- MongoDB running locally (`mongodb://127.0.0.1:27017`) or a MongoDB Atlas connection string

### Installation

```bash
# 1. Install dependencies
npm install

# 2. Create your environment file
cp .env.example .env
# Edit .env and set JWT_SECRET and MONGO_URI

# 3. Load the sample stocks
npm run seed

# 4. Start the development server (auto-reload)
npm run dev

# or start in production mode
npm start
```

On success you should see:

```
MongoDB connected: 127.0.0.1:27017
Stock simulator API listening on http://localhost:5000
```

Check that the server is up:

```bash
curl http://localhost:5000/api/health
```

## Environment Variables

| Variable | Default | Description |
|---------|---------|-------------|
| `NODE_ENV` | `development` | Set to `production` to enforce a custom `JWT_SECRET` |
| `PORT` | `5000` | HTTP port |
| `MONGO_URI` | `mongodb://127.0.0.1:27017/stock_sim` | MongoDB connection string |
| `JWT_SECRET` | `dev-secret-change-me` | Secret used to sign tokens. **Required in production.** |
| `JWT_EXPIRES_IN` | `7d` | Token lifetime (any `jsonwebtoken` duration string) |
| `CLIENT_ORIGIN` | `http://localhost:3000` | Allowed CORS and Socket.IO origin (your React app) |
| `STARTING_CASH` | `100000` | Cash given to each new account |
| `TICK_INTERVAL_MS` | `2000` | How often prices update and broadcast |
| `PERSIST_INTERVAL_MS` | `10000` | How often prices are written to MongoDB |

## REST API

All responses are JSON. Errors have the shape `{ "error": "message" }`.

Protected routes require the header:

```
Authorization: Bearer <token>
```

| Method | Endpoint | Auth | Description |
|-------|----------|------|-------------|
| `GET` | `/api/health` | No | Health check and uptime |
| `POST` | `/api/auth/register` | No | Create an account |
| `POST` | `/api/auth/login` | No | Log in and receive a token |
| `GET` | `/api/auth/me` | Yes | Get the current user |
| `GET` | `/api/stocks` | No | List all stock quotes |
| `GET` | `/api/stocks/:symbol` | No | Get one stock quote |
| `POST` | `/api/trades` | Yes | Place a market order |
| `GET` | `/api/trades/history?limit=50` | Yes | Recent trades (max 200) |
| `GET` | `/api/portfolio` | Yes | Portfolio summary and holdings |

### Examples

**Register**

```bash
curl -X POST http://localhost:5000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"Ada","email":"ada@example.com","password":"supersecret"}'
```

**Buy 10 shares of AAPL**

```bash
curl -X POST http://localhost:5000/api/trades \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"symbol":"AAPL","side":"buy","quantity":10}'
```

**Response**

```json
{
  "transaction": {
    "symbol": "AAPL",
    "side": "buy",
    "quantity": 10,
    "price": 190.42,
    "total": 1904.2
  },
  "cash": 98095.8,
  "holdings": [
    { "symbol": "AAPL", "quantity": 10, "avgCost": 190.42 }
  ]
}
```

**Portfolio**

```bash
curl http://localhost:5000/api/portfolio -H "Authorization: Bearer $TOKEN"
```

Returns `cash`, `holdingsValue`, `equity`, `startingCash`, `totalReturn`, `totalReturnPercent`, and a `holdings` array with per-position market value and unrealized P&L.

## Real-Time Events (Socket.IO)

Connect with the same JWT used for REST. Connections without a valid token are rejected.

```js
import { io } from 'socket.io-client';

const socket = io('http://localhost:5000', {
  auth: { token: localStorage.getItem('token') },
});

socket.on('market:snapshot', (quotes) => { /* full list on connect */ });
socket.on('market:tick', (quotes) => { /* updated quotes every 2s */ });
socket.on('trade:executed', ({ transaction, cash }) => { /* your fills only */ });
```

| Event | Direction | Payload |
|------|-----------|---------|
| `market:snapshot` | Server → client | Array of all quotes, sent once on connect |
| `market:tick` | Server → client | Array of quotes that changed this tick |
| `trade:executed` | Server → client | `{ transaction, cash }`, sent only to the user who traded |

Each quote has this shape:

```json
{
  "symbol": "AAPL",
  "name": "Apple Inc.",
  "sector": "Technology",
  "price": 191.07,
  "previousClose": 190,
  "change": 1.07,
  "changePercent": 0.56,
  "dayHigh": 192.3,
  "dayLow": 188.9,
  "volume": 1284210,
  "lastUpdated": "2026-10-16T06:40:12.000Z"
}
```

## Design Notes

- **In-memory prices, periodic persistence.** Ticks and quote reads come from memory, which keeps the feed fast. The database receives batched writes every `PERSIST_INTERVAL_MS`.
- **Trades without multi-document transactions.** `tradeService` reads the user, computes the new state, and writes it only if `updatedAt` hasn't changed. On a conflict it retries up to three times. This works on standalone MongoDB as well as replica sets and Atlas.
- **Fills at the quoted price.** Market orders execute at the current simulated price, with no slippage or commissions. These are easy to add in `tradeService.js`.
- **Money rounding.** All currency values are rounded to two decimals through `utils/money.js`.
- **Validation.** Quantities must be positive integers up to 1,000,000. Symbols and sides are validated before any database work.

## Limitations and Roadmap

Current limitations:

- Only market orders are supported. Limit and stop orders are not implemented.
- Prices are simulated and reset to the seed values if the database is reseeded.
- `previousClose` never changes, so daily change is measured from the seed price.
- No automated test suite is included yet.

Possible next steps:

- Limit and stop orders with a matching loop
- Daily session reset (open and close prices)
- Leaderboard by total return
- Price history endpoint for charting (OHLC candles)
- Unit and integration tests (Jest and Supertest)
- Docker Compose setup with MongoDB
- React client
